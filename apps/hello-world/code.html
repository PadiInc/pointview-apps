Hello World on CNS/CP

Two Pointview apps on the hello.world Connection Profile. The Initiator sends a message to every Responder; each Responder answers one Initiator at a time. The highlighted lines are all the CNS/CP there is. Everything else shows people what's happening.

The YAML ties each app to a side

The only place the role appears. The code never names it.
